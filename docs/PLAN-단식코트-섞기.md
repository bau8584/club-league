# PLAN — 단식 코트 섞기 + 명단 설정 정리

상태: 만듦(dev, 2026-11-26). DB 적용 전 — `db/migrations/2026-11-26_single_courts.sql`(소유자 승인 뒤 적용). 화면은 로그인이 필요해 눌러 보지 못함.

## 배경 (2026-11-26 `[리그] 대기열: 단복식 섞기`)
- 오늘 한 리그(코트 3, 남녀 따로)에서 선생님이 [+복식][+복식][+단식]을 손으로 23번 눌렀다. 코트 하나를 단식으로 쓴 것.
- [다음 경기 채우기]·자동 채우기는 명단의 종목(복식)으로만 만들어서 한 번도 안 썼다.
- 명단 설정의 "줄 서서 기다려요 / 모두 동시에 해요"는 이름만으로 차이를 몰랐다(소유자).

## 정한 것 (A안)
- 명단 설정: 카드 이름 = [차례대로 해요(배드민턴·탁구)] / [다 같이 해요(공기놀이·팔씨름)].
  차례대로를 고르면 그 아래 코트(안 셈 / 1~6), 복식이고 코트 2개 이상이면 "그중 단식 N개". 다 같이면 코트 줄이 안 보인다.
- 대기열의 [코트]는 지금 값 + "코트 수 바꾸기(명단 바꾸기)" 길 + 자동 채우기 스위치만. 코트 칩은 명단 설정으로 옮김.
- 단식 코트가 있으면: 채우기·자동은 줄의 종류 비율을 코트 비율에 맞춰 섞는다(`src/domain/court-mix.ts`). 복식이 안 되는 2~3명은 단식. [+]는 하나(종류 알아서). 없으면 [+복식][+단식] 그대로.
- 서버: 빈 코트(1~N−S 복식, 나머지 단식)에 그 종류의 가장 앞 줄. 없으면 아무 줄(코트를 비우지 않는다). 단식 코트 0 = 옛 규칙 그대로.
- 목록·교실 화면: 경기 중인 줄을 맨 위로(번호를 건너뛰어 코트에 들어가므로).
- 방식(다양성·밸런스·실력)은 그대로 대기열 화면. 단식·복식에 똑같이 적용.

## 버린 방법
- 섞기를 코트와 떼어 "복식 2 : 단식 1" 비율로 정하기 — 코트 없이 섞어 쓴 실제 사례가 없어 설정만 늘어난다. 코트가 있을 때는 비율 = 코트 배분.
- 카드를 없애고 코트 줄에 "다 같이" 칸 넣기(B안) — "다 같이"와 "안 셈"이 헷갈린다.
- 남는 아이만 단식(설정 없음) — 단식 수가 인원 따라 들쭉날쭉, "코트 하나는 단식"이 안 된다.
