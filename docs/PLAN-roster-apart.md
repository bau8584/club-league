# PLAN — 명단 창: 같이 안 붙이기 · 전학 · 오늘 판 수 · 대진 방식 기억 (2026-09-30)

## 끝 기준
1. 명단 창에서 두 학생을 묶으면 대기열을 여러 번 채워도 둘이 한 번도 안 붙고, 다음 수업에도 그대로, 학생·교실 화면엔 흔적 없음
2. 명단 창에서 전학 감/옴 → 관리 탭 안 가도 반영
3. 명단 칩에 오늘 판 수, 새로고침해도 대진 방식 유지

## 한 것 (dev)
- 대진 계산: 떼어 놓은 두 사람은 같은 경기(같은 편·상대편)에 절대 안 넣음. 완화 단계에서도 안 풂. 시험 3개
- 저장: 새 표 `player_apart` (리그·학생 둘만, 이유 칸 없음, 관리 권한자만 읽기)
  - 세션 표에 안 얹은 이유: 세션 표는 기록원 학생도 읽음 → 새 표로
  - 채우기 직전마다 새로 읽음, 읽기 실패 시 마지막 목록 사용
- 명단 창: "누르면 [결석 | 같이 안 붙이기 | 전학]" 모드. 전학 감 = 기존 삭제(숨김·복원 가능), 전학 옴 = 번호·이름 입력
- 칩 옆 "N판"(오늘), 대진 방식은 기기에 반별로 기억
