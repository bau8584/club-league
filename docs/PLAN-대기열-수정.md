### 4번 보강: 10/6 청림초 컬링 실제 경기
- 10:54 수업(남자 12명, 여자 8명): 남자는 7경기, 여자는 2경기만 함 → 2·3번 증상이 그대로 확인됨.
- 남자 쪽은 몇 명이 계속 같이 묶임. 같은 3명이 다시 붙은 경기가 여러 번 있음.
  예: 60aa·a1d4·b7cd가 두 번, 2214·58d7·a524가 두 번.
- 지운 대진은 기록에 없음. 다만 "지워도 똑같은 게 나옴"은 다음 두 가지와 맞아떨어짐.
  - 섞는 값이 늘 0이다.
  - 쉬는 아이들이 늘 같다(빼놓기 규칙 때문).
  - 그래서 입력이 같고 결과도 같다.
- A 묶음에 추가: 같은 4명뿐 아니라 "같은 짝·같은 3명"도 피하도록 점수를 매김.

### 6번 보강 (소유자 확인)
- 자동 채우기를 켠 채로 대진을 지웠다. 줄이 짧아지자 자동 채우기가 2초 만에 다시 채웠다.
- 섞는 값이 늘 같아서 지운 것과 똑같은 대진이 다시 들어왔다.
- 즉 중복 버그라기보다 **4번과 같은 뿌리**다.
- 고칠 것 (소유자 반박 후 수정):
  - 다시 뽑을 때마다 섞는 값을 바꾼다.
  - 방금 지운 대진은 "금지"가 아니라 순위를 낮추는 감점만 준다.
    - 다른 길이 있으면 피하고, 인원이 적어 그것뿐이면 그대로 뽑는다.
- 버린 방법:
  - 지운 직후 자동 채우기 멈춤: 동작이 들쭉날쭉해진다.
  - 지운 대진을 그날 금지: 인원이 적으면 뽑을 대진이 없어진다.
