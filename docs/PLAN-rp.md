# PLAN — RP 설정, 관리자가 안 정해도 되게 (2026-09-17)

상태: 설계 중 · 코딩 전.

## 목표 한 줄

**교사는 리그 시작할 때 RP를 아무것도 안 정한다. 종목이 뭐든 비슷한 주차에 승급이 나오고, 마음에 안 들면 다이얼 하나만 돌린다.**

됐다의 기준: 컬링(1시간 2경기)과 패드민턴(1시간 6경기)이 같은 설정으로 같은 주차에 플래티넘이 나온다.

## 지금 뭐가 문제인가

- 승급 속도는 **한 시간에 몇 경기 붙느냐**가 정하는데, 설정엔 그 개념이 없다. 그래서 컬링은 3주째 플래티넘이 없다.
- 설정이 4단(기준점·승패·보너스·감점)에 수치 30여 개. 속도 하나 바꾸려면 4곳을 만져야 한다.
- 스포츠맨십 감점은 값만 저장되고 실제로 차감하는 곳이 없다.

## 지킬 것

- 우상향(누구나 승급 가능), 하위 보호 — 교육 철학 그대로.
- 기존 리그 무영향: 새 설정은 "값 없음 = 지금 동작". 세부 수치 화면은 없애지 않고 "고급"으로 접는다.
- 큰 구조 변경 없음. settings JSON 키 추가만.

## 아이디어 — "미리 정하기"를 없애는 방법 5가지

앞서 낸 "질문 두 개" 방식은 해보기 전에 답해야 해서 부담이다. 대신 **해보면서 맞추는** 쪽으로.

| | 방식 | 관리자가 하는 일 | 장점 | 약점 |
|---|---|---|---|---|
| ① | **자동 보정** — 리그가 돌면 실제 경기 수를 세서 속도를 스스로 맞춤 | 없음 | 부담 0. 컬링·패드민턴 문제가 저절로 풀림 | 처음 1~2주는 기본값으로 돌아감. 규칙이 뒤에서 바뀌는 게 학생에게 설명 어려울 수 있음 |
| ② | **수업당 RP 총량 고정** — "한 수업에 다 이기면 +30" 식으로 정해 두고, 그날 경기 수로 나눠 경기당 RP를 계산 | 없음 | 종목 무관하게 속도 같음. 규칙이 한 문장이라 학생도 이해 | 2경기 종목은 한 판이 15점이라 한 판 무게가 큼 |
| ③ | **사후 다이얼** — 설정에 "승급 속도" 슬라이더 하나. 언제든 돌리고, 돌린 뒤 경기부터만 적용 | 원할 때 1번 | 미리 안 정함. 되돌리기 쉬움 | 다이얼만으로는 컬링 문제가 안 풀림(①·②와 같이 써야) |
| ④ | **알림형** — 2주 지나면 "지금 속도면 플래티넘이 9주차에 나와요. 빠르게 할까요?" 한 번 묻고, 예/아니오 | 답 1번 | 관리자가 고민 안 하고 결과만 판단 | 알림 놓치면 그대로 |
| ⑤ | **상대 티어** — RP 절대값이 아니라 반 안 순위 비율로 티어 | 없음 | 항상 플래티넘이 나옴 | 남이 잘하면 내가 떨어짐 → 우상향 철학과 충돌. **안 함** |

### 추천 조합: ② + ③ + ④

- **②가 뼈대.** "한 수업 개근+전승 = +30" 같은 한 문장이 규칙. 경기 수는 이미 세션(수업)별로 기록되므로 계산 가능.
- **③이 조절.** 30을 20~40 사이에서 슬라이더로. 라벨은 숫자 대신 "느긋하게 · 보통 · 빠르게".
- **④가 안전망.** 2주차에 예상 도달 주차를 한 번 보여주고 다이얼 권유.

관리자 화면에는 이것만 보인다:

```
승급 속도   느긋하게 ──●── 빠르게
            이 속도면 매주 참여하고 승률 60%인 학생은
            골드 4주차 · 플래티넘 7주차쯤
            [고급 설정 ▸]
```

### 학생 쪽

- 내 기록에 **다음 티어까지 진행바** + "약 N승 남음".
- 경기 결과에 **"왜 +12?"** 한 줄: `기본 +10 · 언더독 +2`.

## 스포츠맨십 — 결정됨(A+B)

교사 권한을 눈에 보이게. 학생 관리 화면에 버튼 두 개:

- **👍 페어플레이 +N** — 사유 고르고 누름.
- **🚨 비매너 −N** — 사유 고르고 누름.

이력에 경기처럼 남고, 학생 화면에도 "페어플레이 +10 (심판 도움)"으로 보인다. N은 설정 1개(기본 10), 티어별 세분화 없음. 지금의 죽은 `redCardPenalty` 값은 이 N으로 옮긴다.

## 기존 리그 — 결정됨

기존 리그도 설정에서 "새 방식으로 바꾸기" 버튼을 누르면 적용. 누르기 전엔 지금과 똑같이 동작. 바꾼 뒤 경기부터만 새 계산.

## 순서

1. **미리보기 카드**만 먼저 — 지금 설정 화면에 "이 속도면 플래티넘 N주차" 표시. 계산만, 변경 없음. 컬링 리그로 맞는지 검증.
2. **② 수업당 총량 방식** + ③ 다이얼. 새 리그 기본, 기존은 버튼.
3. **스포츠맨십 버튼 두 개.**
4. **학생 진행바 · "왜 +12"** 풀이.
5. ④ 알림.

브랜치 하나 = 한 단계.
