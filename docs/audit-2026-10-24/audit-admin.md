## (A) 첫 리그 만들기 → 첫 경기 → 학생에게 보여 주기 (school 기준)

| 단계 | 누름 수(최소) | 읽어야 하는 문구 | 정해야 하는 것 | 막힐·헷갈릴 점 |
|---|---|---|---|---|
| 1. 로그인 | 1~2 (구글 버튼 + 계정 고르기) | 로그인 안내 | 없음 | `/school`이 아니라 `/`로 들어오면 **클럽 로비**가 뜨고, 개설 폼 기본값도 "동호인 리그"다(`Lobby` 72). 만든 뒤에는 유형을 바꿀 길이 없다 [확인] |
| 2. 리그 개설 | 2 + 글자 입력 1 ([새 리그 개설하기] → 학교 이름 → [리그 개설 완료]) | 배너 2줄, 창 안내 1줄, 유형 설명, 성별 설명, (펼치면) 성향 4종 | 리그 유형(기본값 있음), 성별 사용 켜기/끄기, (선택) 리그 이름·시즌·성향 | 학교 로비에서도 "동호인/학교" 고르는 칸이 그대로 보인다(`Lobby` 715-745). 리그 이름 칸 안내가 학교에서도 "'클럽이름 리그'로 자동 생성"(`Lobby` 874). 성향 프리셋 설명에 "티어 기준점·승패 점수·보너스·패널티"(`Lobby` 902) — 접혀 있어 큰 문제는 아님 |
| 3. 리그 첫 화면 | 0 (개설하면 바로 리그로 들어감, `Lobby` 258-262) | "아직 학생 명부이 없어요" 배너 | 없음 | 문구 조사 오류 "명부**이**"(`League` 619, `league-terms.ts` roster="학생 명부") [확인] |
| 4. 명단 넣기 | 2 + 붙여넣기 ([학생 명부 붙여넣기 →] → 붙여넣기 → [명단 등록 (N)]) | 붙여넣기 안내 2줄, 미리보기 표, "N명 인식됨·N줄 건너뜀" | 미리보기가 맞는지 | 붙여넣기·미리보기는 잘 돼 있다. 단 나이스에서 복사해 오는 앱 밖 단계는 안내뿐 |
| 5. **명단 등록 직후** | — | 토스트 "명단을 반영했습니다" | **다음에 뭘 하지?** | 화면이 관리자 › 학생 관리에 그대로 머문다. "이제 첫 경기" 안내·버튼이 없다(`Students` 295-297, 경기 0건일 때 안내하는 코드 없음) [확인]. 35%가 여기서 멈추는 것과 맞물림 [추측] |
| 6a. 첫 경기 — 바로 입력 | 경기장 탭 1 + 선수 A 2 + 선수 B 2 + 점수 4~6 + [경기 결과 등록] 1 + 결과창 닫기 1 ≈ **11~13** | 폼 제목, 슬롯 안내 | 단식/복식(학교 기본 단식, `RecordMatch.tsx` 103) | 성별 켠 리그는 성별 없는 학생마다 1번씩 더 묻는다 |
| 6b. 첫 경기 — 대기열로 | [출석 정하기] 1 + (결석 n) + 운영 방식 1(필수) + [수업 시작] 1 + [다음 경기 채우기] 1 + 줄 누르기 1 + 점수 4~6 + 등록 1 + 닫기 1 ≈ **12~14** | 출석 창 안내, 방식 두 카드, 저장 버튼 아래 안내, 대기열 안내 한 줄 | 줄서기/동시에, 복식/단식, 결석자 | 경기장 화면에 "대기열"과 "경기 결과 입력하기" 두 길이 위아래로 나란히 있어 처음 온 선생님은 어느 쪽부터인지 정해야 한다. 출석 창의 종목 기본값은 **복식**(`Roster` 135), 바로 입력 폼은 **단식** — 서로 다르다 [확인] |
| 7. 학생에게 보여 주기 | PC: 트로피 아이콘 1 + 복사/열어보기 1 = **2** / 폰: 메뉴(⋮) 1 + "공개 순위표 보기·공유" 1 + 복사 1 = **3** | 창 제목·설명 | 없음 | PC에서는 **글자 없는 트로피 아이콘**이 유일한 통로(`League` 351-355). 메뉴 이름은 "공개 순위표", 열리는 창 이름은 "교실 화면 공유"이고 설명은 대기열 얘기(`InviteDialog.tsx` 74, 99-101) — 순위표를 찾던 선생님은 맞게 왔는지 헷갈린다. 점수입력판 아이콘도 글자 없음(`League` 345-349) |

합계: 처음 온 선생님이 첫 경기까지 **약 17~20번 누름 + 붙여넣기 1번**, 정할 것 약 5개(유형·성별·단복식·운영 방식·결석). 숫자 자체보다 **5단계(명단 뒤 다음 걸음 없음)**와 **6단계(두 길 중 고르기)**가 끊기는 지점이다.

club 차이: 개설 때 종목·레벨 체계까지 정함(+2결정). 회원이 직접 기록하게 하려면 설정에서 "경기 입력 방식"을 바꿔야 하는데 기본값은 "관리자만"(`store` 552) — 방장 혼자 다 입력하는 구조로 시작한다.
