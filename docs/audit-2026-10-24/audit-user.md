## (A) 경로별 단계 표

### A-1. 학생 (school)

| 단계 | 화면 | 헷갈릴 점 |
|---|---|---|
| 1. 들어가기 | 선생님이 공유한 "교실 화면" 링크/QR → 교실 화면 | 집에서 폰으로 열거나, 수업 사이 30분 넘게 아무 활동이 없으면 "무엇을 볼까요?" 고르기 화면이 뜬다. "지금 수업 중인 반"을 눌러도 수업이 없으면 같은 고르기 화면이 다시 뜬다(제자리 맴돎). [확인] |
| 2. 고르기 | "무엇을 볼까요?" (학년 → 반 → 내 번호) | 반을 누르는 순간 저장되고 닫혀서, 그 아래 "내 번호" 칸에 번호를 넣을 틈이 없다. 교실 태블릿에서 아이가 반을 하나 누르면 그 태블릿은 "따라가기"가 꺼지고 그 반에 고정된다. [확인] |
| 3. 내 이름 찾기 | 등급 묶음(다이아→브론즈), 묶음 안은 번호순, 이름은 "김○○" | 번호 강조는 폰(고정 모드)에서만, 교실 태블릿(따라가기)에선 안 됨. 명단에 번호가 없으면 "김○○" 여럿을 구분할 수 없다. 5개 묶음을 다 훑어야 내 줄이 나온다. [확인] |
| 4. 내 기록·등급·호칭 이해 | 줄 바닥 막대(다음 등급까지), ⬆(곧 승급), "최고", "N판" | 막대 설명은 머리말 옆 11px 회색 글씨 한 줄뿐. 승패·경기 기록·호칭은 학생이 볼 곳이 없다(호칭은 본인 로그인해야 고를 수 있는 구조라 학교 학생은 영영 없음). [확인] |
| 5. 점수 입력 (QR) | "누구 경기예요?" → 대기열 줄 / 직접 고르기 → 점수판 → [경기 끝] → "이대로 기록할까요?" → [기록] | 점수판 위 아이콘 3개(×·↔·↺)에 글자가 없다. 대기열이 비면 "대기열에 넣을 수 있는 경기가 없어요"(학생은 넣는 사람이 아님). 비기면 기록 불가 안내는 좋음. [확인] |
| 6. 잘못 눌렀을 때 | 점수판 −버튼, 0:0 되돌리기(확인창), 다시 고르기(확인창) | **기록한 뒤에는 학생이 되돌릴 방법이 없고 "선생님께 말하세요" 안내도 없다.** 저장 응답이 끊겨 다시 누르면 같은 경기가 두 번 들어갈 수 있다(직접 고르기). [확인/추측] |
| 7. 결과 보기 | 기록 후 결과 영수증(교사와 같은 창), "오늘 경기 결과" 목록 | 교실 화면은 숫자를 일부러 숨겼는데 영수증은 "+24 RP · 최종 1190 RP", 진 쪽 "−8"과 "굴욕적 완패 💀" 같은 문구가 그대로. 승급 표시는 9px 배지 하나. [확인] |
| 8. 하이라이트 | 로그인한 화면의 [하이라이트] 탭만 | 학생 공개 화면엔 하이라이트가 없다. 선생님 태블릿으로만 볼 수 있음. 내용(연승왕·깜짝 승리·친구 넓히기, 아무 상도 못 받은 학생 챙기기)은 따뜻하게 잘 짜여 있음. [확인] |
| 빈 상태 | 대기열 0 / 명단 0 / 경기 0 | "아직 대진이 없어요." "아직 아무도 없어요." "경기 전" — 짧고 괜찮음. 직접 고르기에서 명단이 0이면 아무 글자 없이 빈칸. [확인] |
| 오류·끊김 | 교실 화면 / 점수입력판 | 교실 화면은 자동 갱신 중 한 번만 실패해도 대기열·등급 전체가 빨간 오류 글씨(대개 영어 "TypeError: Failed to fetch")로 바뀌고 새로고침 버튼도 사라진다. 점수입력판은 열 때 실패하면 "불러오지 못했어요" 문구만, 다시 시도 버튼 없음. [확인] |

| 7. 알림 | 첫 방문 1.2초 뒤 알림 켜기 배너, 아이폰은 홈 화면 추가 안내 | 흐름 자체는 친절함. |
| 8. 랭킹·하이라이트 | 숫자 순위표, 🔥연승(14일 안), 호칭 배지 | 순위 변화(▲▼) 표시는 없음. 새 호칭을 얻어도 알려주지 않아 내 카드를 열어 봐야 안다. [확인] |
