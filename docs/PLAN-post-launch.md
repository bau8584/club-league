## 0. 지키는 원칙 — 기존 리그는 한 글자도 안 바뀐다

60명이 쓰는 앱이 됐다. 모든 수정은 아래를 만족해야 한다.

- **설정값이 없으면 지금 방식.** 새 설정은 기존 리그에 값이 없으므로, "없음 = 현재 동작"이 기본값이어야 한다. 예외는 "막혀 있던 게 풀리는" 방향뿐(성별 팝업).
- **DB는 추가만.** 열 삭제·이름 변경 금지. 새로고침 안 한 태블릿의 옛 화면이 깨진다. 새 열 + 없으면 옛 방식으로 읽기.
- **지금 되는 입력은 결과가 그대로.** 파서처럼 입력을 해석하는 코드는 현재 동작을 테스트로 먼저 박고, 새 코드가 그걸 전부 통과해야 한다.
- 배포 전 확인은 두 가지: `npx tsc --noEmit` + 청림초 컬링 리그에서 "전과 똑같이 보이는지".

## 1. 브랜치 규칙

```
main ─────●──────●──────●─────────────────   ← 배포된 상태. 직접 커밋 금지
           \    /      /              gender  roster  work ──●──●──●──●   ← 3-3·3-5·남녀 따로 (합치기 전)
```

- 처음엔 작업 하나 = 브랜치 하나(`fix/gender-optional`, `feat/roster-parser` — 둘 다 합쳐짐). 그 뒤로는 **단일 `work` 브랜치**에서 이어서 작업한다 — 여러 세션이 같은 폴더를 쓰므로 브랜치를 갈아타면 서로의 작업 트리를 흔든다. 같은 브랜치에서 파일만 안 겹치게.
- 합치기 전 0번의 확인 두 가지. 통과하면 `main`에 합치고 배포.
- 배포 직전 태그: `git tag deploy-YYYY-MM-DD`. 문제 생기면 그 태그로 되돌려 재배포. (`deploy-2026-09-15`는 3-1·3-2 합치기 전 `29d06da`, `deploy-2026-09-15b`가 3-3~3-6까지 합친 `9c4216f`.)
- **배포 방식(확인됨)**: Cloudflare Workers Builds가 GitHub에 연결돼 있다. `main` 푸시 = **즉시 배포**. 다른 브랜치 푸시 = **미리보기 버전만** 생성(배포 아님, 실사용자 영향 없음). 미리보기 주소는 **브랜치 이름이 앞에 붙는다**: work 브랜치 = https://work-club-league.bau8584.workers.dev/ (배포본은 https://club-league.bau8584.workers.dev/). 안 뜨면 대시보드 → club-league → Settings → Domains & Routes → **Preview URLs** 스위치 확인.
- **미리보기도 진짜 DB를 쓴다.** 환경변수가 `main`과 같아서 미리보기에서 경기를 넣으면 실제 리그에 들어간다. 미리보기에서는 읽기만, 쓰기 테스트(경기 입력·명단 등록)는 **테스트용 리그를 따로 개설**해서. 청림초 컬링 리그는 눈으로만 비교.

**표준 형식 참고**: 나이스 학급명렬표 엑셀은 `학년 · 반 · 번호 · 성명 · 성별 · 생년월일` 열, 학교에 따라 `학번(51201)` 열. 한글 출석부는 `번호 이름` 두 열.

**계획** — 한 줄을 칸으로 나눈 뒤 칸마다 정체를 판별:
1. `5학년12반`처럼 단위가 붙은 칸은 그 자리에서 쪼갬 (학년 5, 반 12)
2. 이름 앞에 붙은 숫자를 뗌 — 1~2자리 → 번호, 3~5자리 → 학번(첫 자리 학년, 끝 1~2자리 번호, 가운데 반). 애매하면 번호 1~40 범위로 판단
3. `남/여/남자/여자/M/F` 칸 → 성별 (나이스 명렬표 쓰는 리그는 3-1 문제도 자동 해결)
4. 날짜 칸(`2015.03.02`, `150302`, `2015-03-02`) → 버림
5. 머리글 줄(`번호 이름 성별`, `학년 반 번호 성명`) → 건너뜀
6. 이름 없이 숫자만 → **"번호만 명단"으로 허용**, 화면엔 "5번"으로 표시. 정식 기능으로
7. 성별만 있는 줄(엑셀 세로 복사) → 바로 윗줄 학생에게 붙임
8. `1.` `1)` `①` → 번호
9. 외국 이름 `JANCHIVDORJ MUNKHDUL (뭉흐둘)` → 지금처럼 공백으로 이어 붙임(현재 정상)

**미리보기 강화**: 등록 전에 학년·반·번호·이름·성별 **표**로 보여주고, 이름이 비었거나 숫자인 줄·번호 없는 줄 수를 붉게. 고촌초·충무공 사고는 등록 버튼 전에 눈에 띄어야 한다.

**기존 보호**: 현재 `parseRoster`의 동작을 테스트 파일로 먼저 고정(✅ 3형식 + 단위 섞인 경우). 새 파서가 전부 통과해야 배포.

**이미 잘못 들어간 명단**(고촌초·충무공·5학년4반·6학년 클럽)은 선생님이 "선택 삭제 → 다시 붙여넣기"로 복구 가능. 인디스쿨 댓글이나 덕구랩에 안내 한 줄.

**구현 메모(2026-09-15)**: 파서는 [src/domain/roster-parser.ts](../src/domain/roster-parser.ts)로 옮겼고 테스트 26개([roster-parser.test.ts](../src/domain/roster-parser.test.ts)) — 앞 12개가 "기존 동작 고정". 위 계획 1~9 전부 구현. 실제 DB의 네 리그 명단(5학년4반 21·6학년 클럽 10·고촌초 38줄·충무공 131)을 돌려 전부 정상. 덤으로 "2반 15 홍길동"이 15학년이 되던 것과, 다시 붙여넣으면 DB 성별이 미지정으로 되돌아가던 것을 고침. 미확인: 로그인 벽 때문에 미리보기 표는 눈으로 못 봄.
