# 코트 안내 + 대기열 바꾸기 확인 창 없애기 (2026-09-30)

## 끝 기준
1. 대기열 선수를 누르면 확인 창 없이 바로 바뀐다 — 코드 완료
2. 코트 수를 안 정하면 두 화면 모두 지금과 똑같다 — 코드 완료, 화면 확인 전
3. 코트 수를 정하면 앞쪽 줄에 "○코트 경기 중" 테두리, 경기가 끝나면 교실 화면에 "○코트 비었어요! #7 ○○ 들어가세요"가 크게 — 코드 완료, DB 적용·화면 확인 전

## 결정
- 코트 수는 선택(기본 "안 씀"). 선생님 대기열 아래 `코트` 칸에서 고름. 세션 행에 저장 → 다음 수업에도 남음.
- 코트 번호는 서버가 매김(DB 트리거). 기기마다 셈하면 태블릿 새로고침 때 어긋남 — 버린 방법(B).
- 코트 번호 없이 "경기 중"만 — 버린 방법(C).
- 안내는 교실 화면에 크게(20초), 선생님 화면엔 한 줄.

## 남은 일 (순서 중요)
1. **DB 적용**: `db/migrations/2026-09-30_court_count.sql` 을 Supabase SQL 편집기에서 실행(소유자).
   적용 전에 `dev`를 main에 합치면 코트 칸을 누를 때 저장 실패 토스트가 뜬다(다른 동작엔 영향 없음).
2. 화면 확인: 코트 2개로 두고 결과 입력 → 교실 화면에 안내가 뜨는지, 끄면 전과 똑같은지.
