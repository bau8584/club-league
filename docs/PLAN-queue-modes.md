## 처음 계획
1. **운영 방식 둘로 나누기** — 세션 시작 때 "줄 서서 기다려요 / 모두 동시에 해요" 카드(추천 B안).
   - 줄서기: 지금 대기열 + 남김 규칙. 코트 수는 그다음에 물음.
   - 대진표(가위바위보처럼 전원 동시): [다음 라운드] 하나. 라운드 전원 끝나면 전체 재배치(먼저 끝난 아이끼리 바로 붙이면 같은 반복이 생김).
   - 기존 세션(설정값 없음) = 지금 동작(줄서기). 새 세션부터 고르게.
2. **버튼 이름** — "한 바퀴"는 이제 "전원 한 판씩"이 아님. 후보: [다음 경기 채우기]+[+1] (추천) / [놀고 있는 친구들 넣기]/[한 경기만 더] / [대진 짜기] 하나. 자동 스위치는 "자동으로 채우기". 이름은 소유자가 정함.

## 버린 방법
- 노는 사람 8명 모일 때까지 기다리기: 끝난 두 조끼리만 갇혀 돎(16명·2코트 반복 28판 그대로).
- 반복될 때 대기 경기 다시 짜기("가"안): 화면에 뜬 이름이 바뀜. 남김 규칙이 같은 효과를 이름 안 바꾸고 냄.
- 코트 수 +2: 대기열이 반 전체를 담으면 다시 같은 함정.
- +1경기 없애기: 세션 39/67개, 경기 38%가 +1로 만들어짐. 코트 수 모를 때 비상구.
- 동점 순서(seed) 섞기만: 줄서기 반복에는 효과 없음(연타 때만 원인).
