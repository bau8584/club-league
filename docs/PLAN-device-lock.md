# PLAN — 입력용 기기 잠금 (2026-09-28)

인디 리그 글 댓글(9/22): 선생님 태블릿을 띄워 두고 아이들이 점수를 넣게 했더니 옆 탭 랭킹을 계속 봄 → "입력 전용 화면이나 탭 이동 시 비밀번호" 요청.
대조해 보니 지금은 **관리 탭까지 아이 손에 열려 있음**(태블릿이 선생님 계정 로그인 상태) — 기록 삭제·설정 변경 가능.
9/15 "화면 잠금 안 만든다" 결정을 이 근거로 뒤집음(DECISIONS 9/28).

## 정한 것 (소유자 9/28)
- 기본 **꺼짐**. 수업 때 안 잠그고 싶은 선생님은 아무것도 안 함. 기존 리그 동작 그대로.
- 잠글 기기에서 **[🔒 이 기기 잠그기]** 버튼 → 그 기기만 잠김. 안 누른 기기(선생님 폰 등)는 그대로.
- 버튼을 **처음 누르면 핀 4자리 설정 창**. 이후엔 바로 잠김.
- 잠기는 탭: **랭킹 · 하이라이트 · 관리**. 경기장(입력)은 열림.
  - 확인 필요: 시즌 요약 탭(순위가 보임), 로그아웃 버튼도 잠금 안쪽에 둘지 → 둘 다 잠그는 쪽 추천(로그아웃 → 구글 한 번 톡 재로그인 경로 차단).
- 핀으로 풀면 **경기장으로 돌아올 때 저절로 다시 잠김**. 새로고침·새 탭도 잠긴 상태로 시작.
- 핀 저장 = **리그 설정(settings) 안 한 줄** — DB 열 추가 없음. 값 없음 = 지금 동작.
  "이 기기 잠김" 표시 = 그 기기 브라우저 저장소.
- **핀 잊음** → 잠금 화면엔 안내 한 줄만("다른 기기에서 관리 설정을 여세요"). 선생님 폰으로 로그인 → 관리 설정에서 핀 보기·바꾸기 / [잠금 전부 풀기].

## 버린 방법
- 옛 잠금(6/22 `a6d968a`에서 삭제한 LockGate) 그대로 되살리기 — 코드를 리그 만들 때 정해야 했고(안 정하면 잠금 무효), 풀면 수동으로 다시 잠가야 했음.
- 핀을 기기에만 저장 — 잊으면 찾을 길 없음.
- 잠금 화면의 "핀 잊음 → 구글 재로그인" — 태블릿에 저장된 구글 계정이면 아이가 한 번 톡으로 뚫음.
- 리그 모든 기기 잠금 — 선생님 폰도 매번 핀 입력.
